# グループ化２
以下は、HTML要素のスタイルをCSSで編集する大まかな流れです
- HTML要素にclass属性をつけ、任意のクラス名（グループ名）を指定する
- 指定したクラス名のスタイルをCSSで設定する

今回は先ほど囲んだ「div」にcardというクラス名を指定していきます。

```html
<div class="card"><!-- ←New! -->
<h1>山田太郎</h1>
<img src="画像のリンク先">
<p>1-1</p>
<p>趣味：プログラミング</p>
<p>一言：よろしくお願いします。</p>
</div>
```

これで、HTML部分はほぼ完成です！
次はCSSを使って見た目を整えていきます👊
