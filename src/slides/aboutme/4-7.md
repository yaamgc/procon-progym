# 見た目を整えよう
角ばった印象を消したいので、カードと要素に丸みをつけます。丸みをつけるプロパティにはborder-radiusを使います。

値は、100%を指定することで要素を完全な円や楕円にすることができます。
```css
.card{
    background-color:white;
    margin: 100px auto;
    padding: 50px;
    width: 400px;
    text-align: center;
    border-radius: 20px; /* New! */
}

img{
    width: 250px;
    height: 250px;
    border-radius: 100%; /* New! */
}
```
![3-5-0](/image/css4.png)

必要に応じて以下のようなbox-shadowプロパティを使って影もつけてみましょう。
```css
box-shadow: 3px 5px 30px #06769b;
/* 値は横方向のずれ 縦方向のずれ ぼかしの奥ゆき 色の順*/
```
