# 縦幅、横幅を調整
縦幅を指定するプロパティは**height**、横幅を指定するプロパティは**width**を使います。

現在cardの横幅が大きすぎるので、widthを400pxに指定します。
```css
.card{
    background-color:white;
    margin: 100px auto;
    padding: 50px; 
    width: 400px;/* ←New! */
}
```

imgのサイズも調整しましょう。
```css
img{
    width: 250px;
    height: 250px;
}
```
