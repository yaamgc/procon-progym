# card内の要素を中央寄せ
```css
text-align:center;
/* 中央寄せ */
text-align:left;
/* 左寄せ */
text-align:right;
/* 右寄せ */
```
のように、cardにtext-alignを指定することで、カード内の**中身**の要素を中央寄せ、左寄せ、右寄せにすることができます。

今回は中央寄せにしたいので、centerを指定します。
```css
.card{
    background-color:white;
    margin: 100px auto;
    padding: 50px;
    width: 400px;
    text-align: center;
    /* ↑New! */
}
```
