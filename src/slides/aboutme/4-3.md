# 色をつけよう
CSSを使ってカードと背景に背景色を付けていきます。
色を指定するプロパティには以下のようなものがあります。
```css
color //文字色を指定するプロパティ
border-color //枠線の色を指定するプロパティ
background-color //背景色を指定するプロパティ
```
今回は背景色を指定するプロパティを使いたいので、 **background-color** を使います。

bodyとcardの背景色を以下の例のように設定しましょう。（色はお好みで大丈夫です）
```css
body{
    background-color: rgb(0, 140, 255);
}
.card{
    background-color:white;
}
```
