# marginとpaddingを理解する
- marginは要素の**外側**の余白
- paddingは要素の**内側**の余白

を指定するプロパティです。
![2-2-0](/image/image.png )


値の指定方法は、以下の例のように値の数によって変わります。

```css
margin: 10px; /* 上下左右に10px */
margin: 10px 20px; /* 上下に10px、左右に20px */
margin: 10px 20px 30px; /* 上に10px、左右に20px、下に30px */
margin: 10px 20px 30px 40px; /* 上10px、右20px、下30px、左40px */
```

※```px```はピクセルという単位です。よく使います。

また、marginの水平方向の値に```auto```を指定することで、その要素を中央寄せにすることができます。

これらを踏まえて、
### cardの**上側**と**内側**に余裕を持たせ、**中央寄せ**

にしようとするとcardの中身は

```css
.card{
    background-color:white;
    margin: 100px auto;/* ←New! */
    padding: 50px; /* ←New! */
}
```
となります。
