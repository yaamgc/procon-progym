# ひな形を用意しよう
index.htmlファイルを選択し、コードを書く前に必要な**ひな形**を用意します。

白紙の状態で、「!」を入力し、Tabキーを押すことで、以下のようなHTMLの基本的なひな形が自動で展開されます。
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>
<body>
    
</body>
</html>
```
書いてることは大体こんな感じです。
```html
<HTML5であることを宣言します>
<HTML これは英語で記述されてます>
<基本情報の最初>
    <文字コードは"UTF-8"です><!-- （文字化け防止） -->
    <スマホの表示にも対応させます>
    <タイトル>Document</タイトル>
<基本情報の最後>
<内容の最初>
    
<内容の最後>
</HTML>
```
大体は理解しておきましょう。
特に、**head要素には基本情報**、**body要素には内容**を記述することはおさえておいてください。
