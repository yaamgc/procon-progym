# 画像を挿入する2
自己紹介用画像を用意し、「自己紹介サイト」フォルダに移動させた後、
```html
<img src="画像のリンク先">
```
を使って、index.htmlに画像を配置していきます。

画像のリンク先は、VScodeの左側のエクスプローラーから対象の画像ファイルを右クリックし、「相対パスをコピー」を押すことで取得できます。

名前の下に追加してみましょう。
```html
<h1>山田太郎</h1>
<img src="画像のリンク先">
<!-- ↑New! -->
<p>1-1</p>
<p>趣味：プログラミング</p>
<p>一言：よろしくお願いします。</p>
```
![3-5-0](/image/html2.png )
これで画像が表示されるようになったはずです。
