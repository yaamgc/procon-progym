# CSSを記述するための準備
まずは、index.htmlを作成した時と同じ要領で、自己紹介サイトフォルダに「style.css」を作成してください。

次に、index.htmlとstyle.cssを紐づけるために、index.htmlのhead要素内に、
```html
<link rel="stylesheet" href="style.css">
```
と記述しましょう。

（ドパガキはデカい字を読むだけでもOK👌）

linkタグは外部ファイルを読み込むためのタグで、rel属性はファイルとの関係性(relation)、href属性はファイルのURLを設定するための属性です。

つまりこれは、
### ***「style.cssというスタイルシート（外部CSSファイル）を読み込みます。」*** 
と書かれているわけです。
